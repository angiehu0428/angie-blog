## 為什麼做這個?

每個 IP 都要在 IG、Threads 的簡介放一個「傳送門」,把官網、商店、社群、合作洽詢集中在一頁。第三方服務用起來綁手綁腳:有浮水印廣告、改版就要重排、數據看不清楚,連結一多也很難統一管理。所以自己做一套,團隊在同一個後台管理所有 IP 的頁面。

## 這是什麼?

團隊內部使用的**一頁式傳送門(link-in-bio)工具**。編輯器左邊是區塊清單、右邊是手機預覽,直接拖拉排序;頁面支援多語與深色模式,活動期間可以切換活動模式。同一套系統也管理短網址,並能產生可追蹤掃描次數的 QR code。

## What is this? (English)

An in-house **link-in-bio page builder**. Each IP gets its own page, edited with drag-and-drop blocks and a live phone preview, with drafts, publishing, and rollback. Pages support multiple languages and dark mode, plus an event mode. The same system manages short links and generates trackable QR codes.
