## 為什麼做這個?

一份完整的向量原稿(例如一整套角色設計)常常要拆開來用在不同地方——每個元素分開存檔、編號,還要準備預覽圖。手動做一次要拆檔、命名、對照,一份圖庫做完常常是一整天,原稿還有被手滑改到的風險。

## 這是什麼?

團隊在用的 **Illustrator 圖庫整理外掛**。開啟原稿、選好標題與編號規則,工具自動把每個元素拆成單張、依序編號,產出封面與預覽 PDF——原稿全程不動。

## What is this? (English)

An internal **Illustrator plugin for asset library automation**. Point it at a complete vector artwork file and it splits every element into its own numbered, editable file, with a cover image and preview PDF — leaving the original untouched.
