## 為什麼做這個?

代理圖像授權,常常要把一份完整的向量原稿(例如一整套角色設計)拆給不同客戶用在不同地方——每個元素分開存檔、編號、還要準備預覽圖讓客戶挑。手動做一次要拆檔、命名、對照,一份圖庫做完常常是一整天,而且原稿還有被手滑改到的風險。

## 這是什麼?

Hu Creates 團隊在用的 **Illustrator 圖庫整理外掛**。開啟完整向量原稿,選好標題與編號規則,工具會自動把每個獨立元素拆成單張、依序編號命名、產出對應的封面圖與預覽 PDF——原稿全程保持不動,拆出的檔案獨立存放到指定資料夾。

## 特色

- **自動拆檔編號**:不用一張張手動另存,元素順序與命名一次到位
- **原稿零風險**:所有拆解與輸出都是另存新檔,原始向量稿不被覆寫
- **給客戶看的預覽**:同步產出封面圖與 PDF,不用另外做簡報
- **固定安裝入口**:Mac 同事一次安裝,之後開啟就自動檢查更新版本

## What is this? (English)

An internal **Illustrator plugin for asset library automation**, used at Hu Creates. Point it at a complete vector artwork file, set a title and numbering scheme, and it automatically splits every individual element into its own numbered, editable AI file — plus a matching cover image and preview PDF — while leaving the original artwork completely untouched.
